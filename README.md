# Prima Materia Coaching

Website source for [primamateriacoaching.com](https://primamateriacoaching.com), a solo coaching practice.

## What this business is

Prima Materia is a **1:1 alchemical coaching and somatic bodywork practice**, run by Imen. It uses the traditional five classical elements (Earth, Water, Fire, Air, Ether) as a framework for personal transformation work, combining somatic bodywork, energy work, and coaching over a minimum three-month container, in person in Berlin or remote via video call.

**Industry:** wellness, coaching, and somatic bodywork services for individuals.

**This is not, and has no connection to, cryptocurrency, blockchain, digital tokens, trading, or any financial/investment product.** The words "Alchemy" and "Prima Materia" are used here in their traditional, historical sense — the classical alchemical stages of personal transformation (*nigredo*, *albedo*, *rubedo*) — not as branding for a digital asset, exchange, or crypto project of any kind. No part of this site offers, promotes, or links to any cryptocurrency service.

## Site structure

Static site, no build step, hosted on GitHub Pages.

| Path | Purpose |

| `impressum.html` | German legal notice (Impressum, §5 DDG) |
| `datenschutz.html` | Privacy policy (Datenschutz) |
| `css/style.css` | Shared stylesheet |
| `js/script.js` | Nav, cookie consent, contact form, contact-link de-obfuscation |
| `images/` | Site imagery, icons, logo |
| `llms.txt` | Plain-text business summary for AI/LLM crawlers |
| `robots.txt`, `sitemap.xml` | Standard SEO/crawler files |
